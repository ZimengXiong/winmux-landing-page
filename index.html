sidebar-first window manager for macOS

A powerful project-based, sidebar-first window manager for macOS. Tab groups, intent zones, multi-monitor support, and projects that just make sense.

# features at a glance

integrated status bar

native swift sidebar indicator. always in sync with windows & spaces with zero lag.

intent zones

arrange, tile, and stack windows intuitively via hover zones without memorizing keyboard chords.

tab groups

combine any unrelated applications (finder, browser, terminal) into unified tabbed windows.

multi-monitor virtual desktops

spaces behave as lightweight virtual views with no duplicate ghost spaces across monitors.

zero SIP required

built on the Aerospace virtualization framework without compromising macOS system security.

single-tap shortcuts

single-tap modifier keys to launch browser profiles or workspaces in under 2 seconds.
